## Purpose

미인증 방문자가 NexusWiki의 원문·위키 이중 인용 가치를 공개 홈에서 직접 이해하고, 어떤 화면 크기나 입력 방식에서도 쇼케이스를 탐색한 뒤 인증 시작 경로로 이동할 수 있게 한다.

## Requirements

### Requirement: 인증 상태를 보존하는 공개 홈
시스템은 미인증 방문자에게 루트 경로의 공개 랜딩을 SHALL 제공하고, 인증된 사용자의 기존 워크스페이스 진입 결정은 MUST 보존해야 한다. 공개 홈을 위해 보호된 워크스페이스 경로의 인증 게이트를 완화해서는 안 된다.

#### Scenario: 미인증 방문자의 루트 진입
- **WHEN** 미인증 방문자가 `/`를 연다
- **THEN** 시스템은 로그인으로 강제 이동하지 않고 공개 랜딩과 인증 시작 링크를 표시한다

#### Scenario: 인증 사용자의 루트 진입
- **WHEN** 인증 사용자가 `/`를 연다
- **THEN** 시스템은 접근 가능한 워크스페이스 수에 따른 기존 자동 진입·선택·온보딩 흐름을 실행하고 공개 랜딩을 표시하지 않는다

#### Scenario: 미인증 방문자의 보호 경로 접근
- **WHEN** 미인증 방문자가 `/w/` 아래의 보호된 워크스페이스 경로를 연다
- **THEN** 시스템은 기존 인증 게이트에 따라 로그인 화면으로 이동시킨다

### Requirement: 반응형 공개 랜딩 탐색과 전환
공개 랜딩은 모바일과 데스크톱에서 가로 넘침 없이 브랜드, 주요 섹션 탐색, 로그인, 무료 시작 경로를 MUST 제공해야 한다. 모든 링크와 버튼은 키보드로 식별하고 조작할 수 있어야 하며, 감소 모션 설정에서는 의미 없는 반복·이동 애니메이션을 MUST 중지해야 한다.

#### Scenario: 모바일 랜딩 탐색
- **WHEN** 방문자가 모바일 너비에서 공개 랜딩을 연다
- **THEN** 시스템은 겹치거나 잘리는 요소 없이 주요 섹션 메뉴와 로그인·시작 경로를 사용할 수 있게 한다

#### Scenario: 키보드 탐색
- **WHEN** 방문자가 키보드만으로 헤더, 쇼케이스, FAQ와 CTA를 탐색한다
- **THEN** 모든 대화형 요소는 명확한 포커스 상태와 현재 선택·열림 상태를 노출한다

#### Scenario: 감소 모션 환경
- **WHEN** 방문자가 운영체제에서 감소 모션을 설정했다
- **THEN** 공개 랜딩은 반복 pulse와 장식용 이동 효과 없이 동일한 정보와 기능을 제공한다

### Requirement: 검증 가능한 라이브 쇼케이스와 FAQ
공개 랜딩은 개인 전문가 위키와 팀 정책 위키 예시를 전환하고, 각 예시의 추천 질문·답변·원문 근거·위키 근거를 함께 MUST 표시해야 한다. FAQ는 질문과 답변의 관계 및 열림 상태를 보조 기술에 MUST 전달해야 한다.

#### Scenario: 쇼케이스 워크스페이스 전환
- **WHEN** 방문자가 다른 쇼케이스 워크스페이스를 선택한다
- **THEN** 시스템은 해당 워크스페이스의 첫 추천 질문과 답변·원문·위키 근거를 함께 표시하고 현재 선택 상태를 노출한다

#### Scenario: 추천 질문 전환
- **WHEN** 방문자가 현재 워크스페이스의 다른 추천 질문을 선택한다
- **THEN** 시스템은 같은 영역에서 질문, 답변, 원문 근거와 위키 근거를 일관되게 갱신한다

#### Scenario: FAQ 열기와 닫기
- **WHEN** 방문자가 FAQ 질문을 열거나 닫는다
- **THEN** 시스템은 연결된 답변의 표시 상태를 변경하고 버튼의 확장 상태를 보조 기술에 전달한다

### Requirement: 실제 제품 계약에 맞는 마케팅 표현
공개 랜딩은 NexusWiki가 구현한 소스 컴파일, 원문·위키 이중 인용, 4채널 검색과 RLS 격리를 SHALL 설명하되, 확인되지 않은 처리 시간·용량·무료 범위·모델 학습 정책을 절대적 보장으로 표현해서는 안 된다(MUST NOT).

#### Scenario: 공개 랜딩 문구 검토
- **WHEN** 방문자가 히어로, 비교, 활용 사례, FAQ와 CTA 문구를 읽는다
- **THEN** 시스템은 실제 제품 계약으로 검증 가능한 기능과 조건부 표현을 사용하고 확인되지 않은 수치나 무조건적 보장을 표시하지 않는다
