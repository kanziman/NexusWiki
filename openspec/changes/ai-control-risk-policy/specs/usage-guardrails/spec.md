## ADDED Requirements

### Requirement: 우회할 수 없는 공통 LLM 정책
시스템은 모든 채팅 LLM 호출의 시스템 프롬프트 앞에 호출 종류별 공통 정책을 워커 경계에서 MUST 주입하고, 정책 버전을 사용량 메타데이터에 SHALL 기록한다. Ask 정책은 인용 규칙과 자료 경계를, 구조화 호출 정책은 자료 경계를 담는다. 워크스페이스가 만든 템플릿은 이 정책을 MUST NOT 제거할 수 있다. 정책은 격리 수단이 아니다.

#### Scenario: 사용자 템플릿에 인용 규칙이 없다
- **WHEN** 인용 규칙을 뺀 워크스페이스 템플릿으로 Ask를 호출한다
- **THEN** 공급자 요청의 시스템 프롬프트 앞에 공통 인용 규칙이 있고 정책 버전이 사용량에 기록된다

#### Scenario: 원문이 지시를 담고 있다
- **WHEN** 수집 원문에 모델에게 내리는 지시문이 들어 있다
- **THEN** 공급자 요청의 시스템 프롬프트에 자료 안의 지시를 따르지 말라는 정책이 있다

### Requirement: 데이터 수집 거부
시스템은 스트리밍과 구조화 출력을 포함한 모든 채팅 요청에 데이터 수집 거부를 MUST 지정한다. 구조화 출력을 지원하지 않는 경로로 내려간 재요청도 MUST 같다.

#### Scenario: 구조화 출력 지원이 없는 경로
- **WHEN** 구조화 출력 요청이 능력 탐지로 거부되어 프롬프트 전용으로 다시 보낸다
- **THEN** 다시 보낸 요청에도 데이터 수집 거부가 있다

#### Scenario: 스트리밍 답변
- **WHEN** Ask 답변을 스트리밍한다
- **THEN** 공급자 요청에 데이터 수집 거부가 있다
