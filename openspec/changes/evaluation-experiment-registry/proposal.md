## Why

회귀 분석 화면(`/showcase/regression`)은 실행 두 개를 비교할 뿐, "무엇을 확인하려던 실험이고 어떤 기준으로 판정했는가"를 기록하지 않는다. 그 결과 같은 재검색 실험을 평가 스크립트는 합계 기준(`no_regression: true`)으로, 화면은 질문 단위 기준(새로 실패 1개 차단)으로 서로 다르게 판정한다. 비용 +50%·p95 +15초 기준은 두 곳에 하드코딩돼 있고, 화면에서는 방문자마다 브라우저에서 바꿀 수 있다. 이 페이지는 인터뷰용 전체 공개 페이지라서, "기준을 먼저 정하고 결과로 판정했다"는 흐름이 기록과 화면 양쪽에서 성립해야 한다.

## What Changes

- 평가 **실험**을 하나의 기록 단위로 둔다. 실험은 목적, 종류, 기준선과 후보의 역할, 연결된 실행 id, 판정 기준, 결정 기록을 가진다.
- 실험 **종류**는 세 가지다. **도입 실험**은 기능을 도입할지 판정하고, **안정성 측정**은 같은 조건에서 결과가 유지되는지 재며, **채점 검증**은 채점 규칙 변경이 판정을 바꾸는지 확인한다. 채택 판정과 결정 상태는 도입 실험에만 있다.
- **채택 정책 v1**을 정본 하나로 정의한다. 회귀는 질문 단위(기준선 통과 → 후보 실패 질문 0개)로 판정하고, 개선 조건(후보 통과 수가 기준선보다 많음), 검사 중단 0개, 비용 증가 50% 이하, p95 증가 15초 이하를 함께 본다. 이후 도입 실험의 기본 기준이다.
- 재검색 실험은 실행 당시 기록된 **원래 기준**(`openspec/changes/archive/2026-11-09-ask-evidence-research/design.md` D4)과 저장된 판정으로 보여 준다. 그 기준이 git에 처음 커밋된 시각이 실행보다 늦다는 사실도 함께 공개한다. 정책 v1로 판정했을 때의 차이는 참고로만 표시한다.
- 새 실행은 하지 않는다. 기존 저장 결과(재검색 OFF/ON 42문항, Ask 반복 측정 30문항, 로컬 재채점 이력)만 실험으로 등록한다.
- 실험, 정책, 결정 기록의 정본은 워크스페이스에 속하지 않는 프로젝트 전역 DB 기록이며 `service_role`만 쓴다. 공개 페이지는 로컬에서 내보내 커밋한 허용 필드 스냅샷만 읽고, 배포 환경은 DB에 접근하지 않는다.
- 화면: 실험별 판정 기준과 출처, 정책 버전, 결정 기록을 읽기 전용으로 보여 준다. 판정 결과가 어느 기준으로 나왔는지 표시하고, 측정 실험에는 채택 배지 대신 측정값을 보여 준다. 실험과 로컬 개발 도구를 사이드바에서 분리한다.
- **BREAKING (화면)**: 허용 기준 입력칸(「기준 바꾸기」)과 브라우저 검토 메모를 없앤다. 브라우저 localStorage에 저장하던 기준값과 메모는 더 이상 읽거나 쓰지 않는다.

## Capabilities

### New Capabilities
- `evaluation-experiment-registry`: 평가 실험·실험 종류·판정 기준(원래 기준과 채택 정책 버전)·결정 기록의 정본 저장과 공개 스냅샷 내보내기 계약.
- `regression-workbench`: 공개 회귀 분석 화면이 실험 기록을 읽어 종류별 판정·측정값·기준 출처·결정 기록을 읽기 전용으로 보여 주는 동작 계약.

### Modified Capabilities
(없음. 재검색 실험의 기존 판정 기록과 `offline-eval-regression-gate`의 PR 관문 동작은 바꾸지 않고 인용만 한다.)

## Impact

- DB: 프로젝트 전역 실험 기록용 신규 마이그레이션. 운영 적용 번호는 `0036` 이후이며 RLS를 켜고 `anon`·`authenticated` 정책을 두지 않는다.
- 스크립트: 기존 결과를 실험으로 등록하는 스크립트, 공개 스냅샷 내보내기 스크립트, `scripts/evidence_research_eval.py`의 하드코딩 기준을 정책 정본과 맞추는 작업.
- 대시보드: `apps/dashboard/components/RegressionDashboard.tsx`, `LocalEvaluationPanel.tsx`, `lib/regression-analysis.ts`, `lib/regression-data.ts`, 신규 공개 스냅샷 `apps/dashboard/content/` 파일.
- 공개 범위: 로컬 전용 실험(재채점 이력)은 공개 스냅샷에 들어가지 않는다.
- 외부 의존성 추가 없음. 모델 호출 비용 없음.
