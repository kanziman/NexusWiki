## Purpose

워크스페이스가 없는 인증 사용자가 이름 하나로 첫 개인 워크스페이스를 만들고 곧바로 진입하도록 한다.

## ADDED Requirements

### Requirement: 빈 워크스페이스 사용자의 개인 온보딩

시스템은 RLS로 보이는 워크스페이스가 없는 인증 사용자에게 온보딩을 제공해야 한다(MUST). 사용자가 유효한 이름을 제출하면 개인 워크스페이스와 전역 고유 슬러그를 만들고 해당 UUID 경로로 이동해야 한다.

#### Scenario: 첫 워크스페이스 생성
- **WHEN** 인증 사용자가 1~100자 이름을 제출하면
- **THEN** 시스템은 owner 멤버십을 가진 personal 워크스페이스를 만들고 `/w/[workspaceId]`로 이동한다

#### Scenario: 중복 이름
- **WHEN** 기존 워크스페이스와 같은 이름을 제출하면
- **THEN** 시스템은 전역 고유 숫자 접미사 슬러그를 만들어 성공한다
