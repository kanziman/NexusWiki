## 1. 공통 대시보드 조판과 업로드 상호작용 (#69)

- [x] 1.1 공통 CSS와 사이드바·워크스페이스·계정 컨트롤의 축소/포커스 상태를 정비한다. **Given** 키보드 또는 축소 사이드바를 사용하는 멤버가 있을 때, **When** 공통 탐색·입력 컨트롤을 순회하면, **Then** 모든 컨트롤의 이름·포커스·상태가 색상 외 단서와 함께 식별된다.
- [x] 1.2 소스 업로드 모달의 파일·URL·텍스트 탭과 파일별 결과·오류·제출 상태를 같은 위계로 정비한다. **Given** 멤버가 소스 업로드 모달을 열었을 때, **When** 등록 모드를 바꾸거나 여러 파일을 제출하면, **Then** 활성 모드와 각 파일 상태와 다음 행동을 독립적으로 확인할 수 있다.

## 2. 소스 목록과 원문 상세 탐색 (#70)

- [x] 2.1 소스 목록 행의 제목과 상세 액션을 같은 workspace-scoped 상세 경로에 연결하고 목록 조판을 정비한다. **Given** 소스가 목록에 있을 때, **When** 제목 또는 상세 액션을 활성화하면, **Then** 현재 워크스페이스의 같은 소스 상세 화면이 열린다.
- [x] 2.2 요청자 Supabase client로 소스·청크·인용 위키를 병렬 조회하고 원문/청크/처리 상태/인용 관계 상세 화면을 제공한다. **Given** 멤버에게 보이는 소스가 있을 때, **When** 상세 경로를 열고 청크를 선택하면, **Then** 허용된 원문과 좌표와 인용 관계만 표시되며 다른 워크스페이스 데이터는 노출되지 않는다.
- [x] 2.3 소스 상세 라우트와 목록 링크 테스트를 추가한다. **Given** 보이는 소스와 보이지 않는 소스 fixture가 있을 때, **When** 라우트와 목록 테스트를 실행하면, **Then** 상세 데이터 전달·직접 링크·일반화된 not-found가 검증된다.

## 3. 위키 라이브러리와 리더 문서 조판 (#71)

- [x] 3.1 위키 라이브러리의 마크업 없는 발췌·검색·카테고리·검증 상태 조판을 구현한다. **Given** 마크다운과 WikiLink가 포함된 문서가 있을 때, **When** 목록을 보거나 발췌문 표현으로 검색하면, **Then** 제어 문법 없는 같은 평문이 표시와 검색에 사용된다.
- [x] 3.2 위키 리더에 허용 목록 기반 표·목록·인용·코드·인라인 서식·WikiLink 렌더링과 안전한 외부 링크 처리를 구현한다. **Given** 지원 마크다운과 안전/위험 URL이 섞인 문서가 있을 때, **When** 리더가 본문을 렌더링하면, **Then** 문서 구조와 WikiLink는 유지되고 실행 가능한 위험 URL은 링크가 되지 않는다.
- [x] 3.3 리더 목차의 heading 위계·현재 절 추적·부드러운 이동·fragment 갱신과 좁은 화면 숨김을 유지한다. **Given** 여러 단계 heading이 있는 긴 문서가 있을 때, **When** 스크롤하거나 목차 항목을 선택하면, **Then** 현재 절과 중첩이 표시되고 해당 heading과 URL fragment가 동기화된다.
- [x] 3.4 위키 리더의 리치 마크다운·WikiLink·위험 URL·목차 회귀 테스트를 추가한다. **Given** 각 지원 문법 fixture가 있을 때, **When** 컴포넌트 테스트를 실행하면, **Then** 의미 요소와 안전 경계가 역할·텍스트·링크 속성으로 검증된다.

## 4. Ask 답변과 백로그 표시 (#72)

- [x] 4.1 Ask 답변이 인용 세그먼트를 제자리에 둔 채 제목·목록·표·인용·코드·인라인 서식과 안전한 링크를 렌더하도록 구현하고 이중 인용 범례를 제공한다. **Given** 마크다운과 원문/위키 인용이 섞인 스트리밍 답변이 있을 때, **When** citations 이벤트 전후를 렌더링하면, **Then** 구조화된 답변과 비활성 placeholder/활성 마커 순서 및 종류 범례가 보존된다.
- [x] 4.2 백로그 목록·상세 패널의 검색·행·참조 문서·소스 추가 동선을 공통 라이브러리 위계로 정비한다. **Given** 한 행에 주제·위키 링크·소스 추가 액션이 함께 있을 때, **When** 각 컨트롤을 따로 활성화하면, **Then** 선택한 패널 또는 경로만 열린다.
- [x] 4.3 Ask 리치 마크다운과 인용 마커 회귀 테스트를 추가한다. **Given** 지원 문법과 인용 alias가 있는 답변 fixture가 있을 때, **When** 스트리밍/해소 상태 테스트를 실행하면, **Then** 의미 구조·마커 위치·위험 URL 비활성화가 검증된다.
