## 1. 골든셋 후보를 근거와 함께 확인

추적: umbrella https://github.com/kanziman/NexusWiki/issues/266. 사용자 승인으로 작업 분해·구현 착수 확정. 하위 이슈: 1절 #267, 2절 #268, 3절 #269, 4절 #270, 5절 #271. GitHub sub-issue 연결 응답 확인 완료. 사용자 요청에 따라 테넌트 리뷰는 생략하되 경계 테스트는 수행한다.

- [x] 1.1 합성 자료 기반 30문항 후보, 버전·지문·원문 구간 검증, 로컬 읽기 응답과 대시보드 후보 상세를 연결한다. 정상·모호성·거절·인용 사례와 미검토 표시를 검증한다.

AC:
Given: 30문항 후보와 합성 원문이 있다.
When: 로컬 작업대에서 문항을 선택한다.
Then: 질문·기대 사실·근거·검토 상태를 확인하고, 원문과 불일치하는 구간은 거부되며 에이전트 작성만으로 사람 검토 완료가 되지 않는다.

## 2. 저장 답변을 사실·인용 기준으로 심사

- [x] 2.1 실제 저장 답변과 검증용 합성 답변을 출처별로 구분해 입력 패키지로 연결하고, 서버 허용 모델·명시적 예산으로 심사하는 로컬 작업과 진행·지표별 결과 UI를 구현한다. 가짜 공급자로 유효 인용과 의미 판정 분리, 근거 부재·형식 오류·비용 미관측·예산 중단·재시작 복구·운영 요청 차단을 검증한다.

AC:
Given: 입력 패키지와 서버의 심사 모델 설정이 있다.
When: 사용자가 모델·문항 범위·예산을 지정해 심사를 요청한다.
Then: 사실·인용·거절 판정과 검증 가능한 구간을 보존하고 비용·미실행을 구분한다. 근거를 추측하지 않으며 조회만으로 호출하지 않고, 운영 요청은 거부한다. 공급자 설정이 없으면 준비 필요로 표시한다.

## 3. 사람 확인과 심사 불일치를 검토

- [x] 3.1 골든셋 검토 완료와 답변별 사람 판정을 별도 제출·보존하고, 코드/LLM/사람 비교·미검토/불일치/심사 불가 필터·지표별 일치도와 오통과·오실패 집계를 연결한다. 입력 변경·동시 검토 충돌·저장 실패·분모 0·합성 예시 집계 분리를 검증한다.

AC:
Given: 일부 표본에 LLM 판정이 있고 일부에만 사람 판정이 있다.
When: 사용자가 근거를 확인해 판정과 이유를 제출하고 불일치 목록을 본다.
Then: 같은 입력·지표의 사람/LLM 통과·실패 쌍만 일치도에 반영하고 분모와 제외 수를 표시한다. 미검토·이전 버전·적용 불가는 성공으로 집계하지 않으며 판정은 재시작 후에도 보존된다.

## 4. 사용 흐름과 검증을 완료

- [x] 4.1 골든셋 후보 확인→명시적 심사→사람 대조 흐름을 로컬 운영 문서에 안내하고 관련 Python·프런트엔드 테스트, typecheck·lint·포맷·변경 strict validation을 새로 실행한다. 데스크톱·모바일에서 실제 표시와 오류 상태를 확인하고, 실제 유료 실행 및 실제 사람 검토 여부를 구현 검증과 구분해 보고한다.

AC:
Given: 앞선 세 흐름이 연결됐다.
When: 문서 절차로 로컬 작업대를 확인하고 전체 관련 검증을 실행한다.
Then: 저장 결과·후보·예시·실제 심사 결과를 구분할 수 있고 검증 실패를 완료로 기록하지 않는다. 실제 사람 라벨과 유료 호출 없이 심사 정확도를 검증했다고 주장하지 않는다.

## 5. 스펙 동기화와 변경 마감

- [x] 5.1 검증된 구현과 delta spec을 대조하고 main spec으로 동기화한 뒤 specs strict validation을 통과시키며 리뷰 및 검증 결과를 기록한다.

마감 순서: 모든 구현·검증 task가 완료된 뒤 archive 안내를 확인하고 아카이브한다. 이후 승인 범위만 커밋하고 멈춘다. PR·푸시는 별도 요청에 따르며 sub-issue는 PR 이후, umbrella는 머지 이후 닫는다. 아카이브 자체를 완료 전 task 조건에 넣으면 순환 조건이 되므로 작업과 마감 절차를 구분했다.

AC:
Given: 구현과 관련 검증이 모두 통과했다.
When: 스펙 동기화·아카이브 검증을 수행한다.
Then: 미완료 task나 실패 검증이 없는 상태만 마감하며 자동 push·PR·유료 심사를 실행하지 않는다.
