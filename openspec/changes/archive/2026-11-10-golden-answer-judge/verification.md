# 검증 기록 — golden-answer-judge

추적: #266 · 하위 작업 #267–#271. 사용자 요구사항·구조·최종 설계·구현 승인 완료.

## 구현 범위

- 30문항 후보: 단일 사실 12, 복수 사실·계산 6, 적용 대상 구분 4, 거절 4, 인용 대조 4. 사람 검토 상태는 모두 미검토다.
- 합성 예시와 기존 저장 모델 답변의 출처를 구분한다. 같은 입력의 반복은 일치도에서 중복 집계하지 않는다.
- 코드 인용 유효성, LLM 의미 심사, 사람 확인을 나란히 표시한다. 과거 입력·심사 프롬프트와 판정·비용 및 사람 검토 개정 이력을 로컬 보존한다.
- 유료 호출 전 체크포인트, 재시작 중단 복구, 비용 미관측·미실행 구분, stale 검토 제출 차단을 포함한다.
- 기존 랜딩 문구 수정은 이번 change 커밋에서 제외하고 작업 트리에 보존한다. 구현 전 원격 main의 #265를 fast-forward로 반영했다.

## 리뷰와 화면 확인

- 스펙 부합 리뷰 r1 `needs_fix` 4건 → 입력 패키지 보존, 호출 전 in-flight 체크포인트, 편집 revision 고정, 잘못된 공급자 응답의 알려진 비용 보존을 수정.
- r2 `pass`. 리뷰어가 Python 23개와 UI·프록시 13개를 별도 재실행해 통과를 확인했다.
- 테넌트 리뷰는 사용자의 명시적 요청으로 생략했다. 운영 403, 동일 출처·고정 경로, 공급자 모형 비용·오류 테스트는 유지했다.
- 로컬 실행기를 기존 기록 보존 후 재시작했다. Aside로 실데이터·읽기 흐름을 확인하고 앱 브라우저에서 1280px·390px 화면을 확인했다. 문항·기대 사실·답변, 미심사·사람 미검토와 분모 0의 미측정 표시를 확인했다.

## 아직 수행하지 않은 것

실제 유료 모델 심사와 실제 사람 라벨링은 수행하지 않았다. 심사 모델·가격·키는 기본 미설정이므로 실행 버튼은 준비 전 비활성화된다. 자동화 테스트의 가짜 공급자 결과나 합성 예시는 실제 모델 성적 또는 사람 기준 정확도 검증을 뜻하지 않는다. 운영 배포·푸시·PR도 수행하지 않는다.
