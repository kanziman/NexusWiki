## 1. 로그인 지식 미리보기 모션

- GitHub sub-issue: [#92](https://github.com/kanziman/NexusWiki/issues/92)

- [x] 1.1 `/login`의 지식 미리보기에 질문·답변 타이핑과 근거 표시 순환을
  복원하고, 헤드라인 “답으로 연결하다.”의 accent 밑줄 및 감소 모션·비가시 탭
  정적 상태를 검증한다.
  - Given: 사용자가 모션을 허용한 상태로 `/login`을 연다
  - When: 지식 미리보기가 시나리오를 재생한다
  - Then: 질문, 답변, 원문·위키 근거가 순서대로 보이고 다음 시나리오로 전환한다
  - Given: 사용자가 감소 모션을 설정하거나 로그인 탭을 숨긴다
  - When: 미리보기가 렌더링되거나 현재 재생이 중단된다
  - Then: 화면은 즉시 완성된 상태로 유지되며 새 타이핑 순환을 시작하지 않는다
  - Given: 사용자가 모션을 허용한 상태로 `/login`을 연다
  - When: 헤드라인이 렌더링된다
  - Then: “답으로 연결하다.” 아래에 accent 밑줄이 그려진다
