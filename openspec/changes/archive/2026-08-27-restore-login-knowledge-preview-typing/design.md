## Context

`LoginKnowledgePreview`는 현재 완성된 시나리오를 9초마다 교체하고, cursor의
깜박임만 CSS로 제공한다. 승인된 v3 템플릿은 질문과 답변을 문자 단위로 순차
표시하고, 근거를 마지막에 노출한다. 제품 메시지와 표시 계약은
[`proposal.md`](proposal.md)와
[`specs/google-authentication/spec.md`](specs/google-authentication/spec.md)를 따른다.

## Goals / Non-Goals

**Goals:**

- 초기 렌더링에서 미리보기가 비어 보이지 않게 하면서 질문·답변·근거의 생성
  순서를 재현한다.
- 비가시 탭과 감소 모션 환경에서 타이머·문자 단위 갱신을 중지한다.
- 헤드라인의 마지막 문장을 CSS accent 밑줄로 강조한다.

**Non-Goals:**

- 실제 LLM 요청이나 인증 흐름을 추가하지 않는다.
- 로그인 외 페이지의 타이포그래피·모션 규칙을 바꾸지 않는다.

## Decisions

### 취소 가능한 React 타이머 시퀀스를 사용한다

클라이언트 컴포넌트가 단계(질문 입력, 답변 생성, 근거 표시, 대기)를 명시적으로
관리하고, 각 문자 갱신은 취소 토큰을 확인한다. 탭이 비가시가 되거나 컴포넌트가
unmount되면 진행 중인 timeout을 정리하고 현재 시나리오를 완성 상태로 둔다.

CSS `steps()`만으로 텍스트를 가리는 방법은 실제 문장 길이·한국어 문자 수에
맞추기 어렵고, 보조 기술에 불완전한 문장을 노출할 수 있어 채택하지 않는다.

### 헤드라인 강조는 CSS pseudo-element로 한정한다

“답으로 연결하다.”를 의미 있는 span으로 감싸고, `::after`의 scale transform으로
accent 밑줄을 그린다. 텍스트 자체나 레이아웃 속성을 애니메이션하지 않아 재배치
비용을 피한다. 감소 모션에서는 밑줄을 즉시 전폭으로 렌더링한다.

### 미리보기 본문은 보조 기술에서 숨긴다

반복되는 데모 문장이 로그인 작업을 방해하지 않도록 시각적 미리보기 본문은
`aria-hidden`을 유지한다. 사람에게 보여 주는 의미는 섹션의 고정 accessible name으로
전달한다.

## Risks / Trade-offs

- [문자별 state 갱신 비용] → 작은 보조 미리보기로 범위를 한정하고 비가시 탭에서
  즉시 중지한다.
- [타이머가 화면 전환 뒤 갱신] → cleanup과 순서 토큰으로 오래된 콜백을 무시한다.
- [모션 민감 사용자에게 방해] → 감소 모션 환경에서 정적 완성 상태를 보장한다.

## Migration Plan

1. 로그인 미리보기와 헤드라인의 모션을 배포한다.
2. 단위 테스트로 단계 전환·감소 모션·unmount cleanup을 확인한다.
3. 문제 발생 시 미리보기 컴포넌트와 로그인 전용 CSS만 되돌린다. 인증 및 데이터
   경로는 변경하지 않는다.
