## Why

NexusWiki의 현재 화면은 인증, Supabase 데이터, API가 모두 준비되어야 검토할 수
있다. 로컬에서 에이전트와 사람이 제품 흐름을 빠르게 검토할 수 있도록, 실제
테넌트나 외부 서비스를 건드리지 않는 결정적 미리보기 경로가 필요하다.

## What Changes

- 개발 서버에서만 접근 가능한 `/preview` 및 하위 화면을 제공한다.
- 목업 사용자·워크스페이스·지식 데이터를 사용해 홈, 소스, 질문, 위키, 백로그,
  설정 흐름을 탐색할 수 있게 한다.
- 질문, 인용 탐색, 탭, 필터 등 검토에 필요한 화면 내 상호작용은 동작하게 한다.
- 저장, 업로드, 초대, 로그아웃처럼 외부 상태를 바꾸는 동작은 네트워크 요청 없이
  미리보기 안내로 대체한다.
- production 환경에서는 미리보기 경로를 404로 처리한다.

## Capabilities

### New Capabilities

- `local-product-preview`: 인증 및 실서비스 데이터 없이 제품 화면을 안전하게
  검토하는 개발 전용 목업 미리보기 경로

### Modified Capabilities

- 없음.

## Impact

- `apps/dashboard/app/preview/`의 개발 전용 라우트와 레이아웃
- `apps/dashboard/lib/`의 타입이 있는 목업 데이터 및 미리보기 경계
- 재사용 화면 컴포넌트의 데이터·행동 주입 인터페이스
- dashboard Vitest 테스트와 로컬 검토 절차
