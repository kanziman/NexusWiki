## Why

그래프 화면에서 카테고리 칩과 시각화 캔버스가 같은 평면에 놓여 있어 필터 조작 영역과 결과 영역의 경계가 불명확하다.

## What Changes

- 그래프 필터·범례를 별도의 도구 영역으로 묶고 캔버스와 구분선·배경·여백으로 분리한다.

## Capabilities

### New Capabilities

- `graph-surface-separation`: 그래프 제어 영역과 시각화 영역의 명확한 시각·접근성 구분

### Modified Capabilities

- 없음.

## Impact

- dashboard graph route and canvas presentation only; graph query and node interaction remain unchanged.
