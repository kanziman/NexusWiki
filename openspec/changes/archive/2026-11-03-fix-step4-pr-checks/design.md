## Context

동기는 proposal.md를 따른다. 승인·적용 통합 스위트는 API 요청과 워커 실행을 함께 검증하며 API 디렉터리에 있어 SEC-03가 특권 DB import를 거부했다.

## Goals / Non-Goals

**Goals:** 기존 통합 검증을 모두 보존하며 실행 책임에 맞게 위치를 이동한다.

**Non-Goals:** 검사 예외 추가, 동적 import로 탐지 우회, 제품 기능·서체 디자인·DB 변경, 운영 배포·머지.

## Decisions

통합 스위트를 worker 테스트로 이동하고 기존 API 테스트의 로컬 전용 픽스처를 명시적으로 재사용한다. 권한 검사도 전체 수집에서 그대로 실행된다. 픽스처 구현 복제는 정리·안전 규칙이 갈라져 기각한다. 보안 스크립트 예외는 검사 계약을 약화하므로 기각한다.

사용자의 2026-11-03 PR 실패 수정 요청으로 범위와 실행을 승인받았다. 제품 계약 변경이 없는 책임 이동이므로 새 delta는 없다.

Vercel 로그는 Next 15.5.22의 Google 폰트 로더에서 URL 확장자 정규식 결과가 null인 실패를 보였다. 기존 세 서체를 `@fontsource-variable` 5.3.0 패키지의 latin normal woff2로 고정하고 `next/font/local`로 self-host한다. 기존 변수·굵기를 유지한다. 공급자 응답 재시도만으로는 재발을 막지 못하며 Next 내부 코드를 패치하면 버전별 유지보수가 생기므로 기각한다. Pretendard의 기존 로컬 로딩 방식과 일치한다.

## Risks / Trade-offs

- 테스트 위치에 따른 픽스처 발견 차이 → 워커 파일 단독 실행과 루트 수집을 모두 확인한다.
- 서체 파일 누락·범위 변화 → 패키지 파일·굵기 메타데이터를 확인하고 실제 프로덕션 빌드로 검증한다.

## Migration Plan

스키마 변경 없이 기존 PR에 커밋하고 CI 결과를 확인한다.
