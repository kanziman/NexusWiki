# 최종 측정 원본 감사

## 2026-11-08 재개 확인

사용자는 계획 게이트의 권장안 선택, 필요한 유료 실행 및 로컬 월 한도 조정을 승인했다. HTTP OFF/ON 추가 반복(pair 2·3)은 실행하지 않고 최종 구현의 유효한 한 쌍만 확보한다.

`/private/tmp/research-rerun-v4/on-1.json`의 q01~q28 행은 v3 원본과 완전히 같다. q29 이후는 판단 출력 256토큰 상한 및 사용자 메시지 말미 지시 추가 뒤 재개됐다. 따라서 한 ON 결과 안에 판단 설정이 서로 다른 실행이 섞였다.

현재 `evaluation-runtime.json`에는 최종 답변 출력 상한 1500만 있고 판단 호출 상한 256과 판단 지시의 해시가 없다. 결과의 `conditions.prompts`는 DB 프롬프트만 해시하므로 코드 안의 판단 지시 변경을 검출하지 못한다. `conditions_match=true`만으로 이번 원본의 동일 조건을 증명할 수 없다.

## 필요한 조치

- 판단 상한과 판단 프롬프트를 실행 조건에 포함하고 재개 시 불일치를 거부한다.
- 혼합 원본은 보존하되 최종 동일 조건 비교 근거로 쓰지 않는다.
- 기존 OFF의 최종 답변 경로 설정·코드 일관성을 확인해 재사용 가능 여부를 판정한다.
- 최종 판단 설정으로 ON 한 회차를 새로 측정한다. 이전 42문항 비용은 $2.113682이므로 약 $2.1을 예상하되 실제 사용량과 중단 여부를 기록한다.
- 원본·공개 export·문서에서 수정 전후 조건과 단일 쌍 한계를 함께 밝힌다.

이 감사는 전체 spec 리뷰를 대신하지 않는다.

## 2026-11-09 최종 측정

- 판단 상한과 판단 지시는 `execution_sha256`(API·워커·core 소스 전체 해시)에 포함된다. 서버 시작 manifest와 평가 시점 지문이 다르면 평가기가 시작을 거부하고, 재개 원본의 조건이 다르면 재개를 거부한다.
- 앞선 최종 실행(`/private/tmp/research-final-20261108/`)의 ON은 q28에서 측정 장애로 중단됐다. 판단 응답이 출력 상한 256에서 `length`로 끝나자 API가 스트림을 도중에 닫아 사용량이 불완전으로 기록됐다. 자동 재시도도 같았다. 설계 D2의 2026-11-09 추가 결정으로 고친 뒤 OFF·ON을 모두 새로 측정했다.
- 새 ON은 r07에서 OpenRouter 크레딧 소진(공급자 402)으로 한 번 중단됐다. 크레딧 충전 뒤 서버를 재시작하지 않은 같은 실행 지문에서 `--resume-from`으로 정상 36행을 유지하고 r07~r12만 다시 실행했다. 중단 원본은 `on-1.partial.json`으로 보존했다.
- 혼합 원본(v4)과 중단 원본(research-final)은 보존하되 비교 근거로 쓰지 않는다. 최종 근거는 `verification.md`의 최종 측정 절이다.
