## MODIFIED Requirements

### Requirement: 반응형 공개 랜딩 탐색과 전환
공개 랜딩은 모바일과 데스크톱에서 가로 넘침 없이 브랜드, 주요 섹션 탐색, 평가 기록 페이지 링크, 로그인, 무료 시작 경로를 MUST 제공해야 한다. 평가 기록 링크는 `/showcase/evaluation`으로 이동하며 대상 페이지를 미리 가져오지 않아야 한다(MUST NOT). 모든 링크와 버튼은 키보드로 식별하고 조작할 수 있어야 하며, 감소 모션 설정에서는 의미 없는 반복·이동 애니메이션을 MUST 중지해야 한다.

#### Scenario: 모바일 랜딩 탐색
- **WHEN** 방문자가 모바일 너비에서 공개 랜딩을 연다
- **THEN** 시스템은 겹치거나 잘리는 요소 없이 주요 섹션 메뉴와 로그인·시작 경로를 사용할 수 있게 한다

#### Scenario: 상단 메뉴의 평가 기록 링크
- **WHEN** 방문자가 데스크톱 상단 메뉴나 열린 모바일 메뉴를 본다
- **THEN** 두 메뉴 모두 FAQ 다음에 「평가 기록」 링크를 보이고, 링크는 `/showcase/evaluation`으로 이동하며, 랜딩을 열었다는 이유만으로 대상 페이지를 미리 가져오지 않고, 모바일 메뉴에서 선택하면 메뉴가 닫힌다

#### Scenario: 키보드 탐색
- **WHEN** 방문자가 키보드만으로 헤더, 쇼케이스, FAQ와 CTA를 탐색한다
- **THEN** 모든 대화형 요소는 명확한 포커스 상태와 현재 선택·열림 상태를 노출한다

#### Scenario: 감소 모션 환경
- **WHEN** 방문자가 운영체제에서 감소 모션을 설정했다
- **THEN** 공개 랜딩은 반복 pulse와 장식용 이동 효과 없이 동일한 정보와 기능을 제공한다
