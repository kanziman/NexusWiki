## Purpose

워크스페이스가 내부 및 후속 공개 URL에 사용할 전역 고유 슬러그를 안전하게 보유하도록 하며, 기존 데이터와 새 생성 요청 모두 일관된 식별 계약을 따른다.

## ADDED Requirements

### Requirement: 워크스페이스는 유효한 전역 고유 슬러그를 가진다

시스템은 모든 워크스페이스에 비어 있지 않은 전역 고유 슬러그를 저장해야 하며(MUST), 슬러그는 1자 이상 80자 이하여야 한다. 슬러그는 소문자 영숫자·한글 음절·하이픈만 사용하고 영숫자 또는 한글 음절로 시작해야 한다.

#### Scenario: 기존 워크스페이스의 슬러그 백필

- **WHEN** 슬러그가 없는 기존 워크스페이스가 존재하는 데이터베이스에 변경을 적용하면
- **THEN** 각 워크스페이스는 `ws-`와 UUID 앞 8자를 결합한 결정적이고 서로 다른 슬러그를 가진다

#### Scenario: 유효하지 않은 슬러그 거부

- **WHEN** 새 워크스페이스 또는 기존 워크스페이스에 공백, 경로 구분자, 점 또는 80자를 넘는 슬러그를 저장하려 하면
- **THEN** 데이터베이스는 해당 쓰기를 거부한다

#### Scenario: 전역 중복 슬러그 거부

- **WHEN** 서로 다른 두 워크스페이스에 같은 슬러그를 저장하려 하면
- **THEN** 데이터베이스는 두 번째 쓰기를 거부한다
