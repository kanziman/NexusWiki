## Purpose

소속 워크스페이스가 이미 있는 인증 사용자가 개수 상한 안에서 셀프서브로 추가 개인 워크스페이스를 만들 수 있는 전용 진입점을 제공한다.

## ADDED Requirements

### Requirement: 소속 개수와 무관한 전용 생성 라우트

시스템은 인증 사용자가 소속 워크스페이스 개수와 무관하게 도달 가능한 전용 라우트를 제공해야 한다(MUST). 이 라우트는 루트 경로(`/`)의 자동 진입 분기(1개 → 리다이렉트, 2개 이상 → 선택 화면)에 영향을 주지 않는다.

#### Scenario: 소속이 있는 사용자가 전용 라우트에 진입
- **WHEN** 소속 워크스페이스가 1개 이상인 인증 사용자가 전용 생성 라우트에 접근하면
- **THEN** 시스템은 워크스페이스 이름 입력 폼을 렌더링한다

### Requirement: 상한 이내 추가 워크스페이스 생성

시스템은 인증 사용자가 상한(3개) 미만의 소속 워크스페이스를 가질 때 이름 하나로 개인 워크스페이스를 생성해야 한다(MUST). 생성 판정은 RLS로 좁혀진 소속 개수를 요청 시점에 서버에서 다시 세어 이루어져야 하며(MUST), 클라이언트 표시 상태만으로 최종 판정해서는 안 된다(MUST NOT).

#### Scenario: 상한 미만에서 생성 성공
- **WHEN** 소속이 3개 미만인 사용자가 1~100자 이름을 제출하면
- **THEN** 시스템은 owner 멤버십을 가진 personal 워크스페이스를 만들고 해당 워크스페이스로 이동한다

#### Scenario: 상한 도달 시 생성 거부
- **WHEN** 소속이 이미 3개인 사용자가 전용 라우트에서 이름을 제출하면
- **THEN** 시스템은 워크스페이스를 생성하지 않고 상한 안내를 반환한다

### Requirement: 상한 도달 시 죽은 링크를 만들지 않는다

워크스페이스 스위처의 생성 진입점은 상한에 도달한 사용자에게 눌러야만 실패를 알게 되는 링크를 보여주어서는 안 된다(MUST NOT).

#### Scenario: 상한 도달 시 진입점 숨김
- **WHEN** 소속이 이미 3개인 사용자가 워크스페이스 스위처를 열면
- **THEN** 시스템은 "새 워크스페이스 생성" 진입점을 렌더링하지 않는다

#### Scenario: 상한 미만에서 진입점 노출
- **WHEN** 소속이 3개 미만인 사용자가 워크스페이스 스위처를 열면
- **THEN** 시스템은 전용 생성 라우트로 이동하는 "새 워크스페이스 생성" 진입점을 렌더링한다
