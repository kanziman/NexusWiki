모든 테이블(`wiki_pages`, `source_chunks`, `prompt_templates`)에 대해 워크스페이스 격리 RLS가 활성화되어 있어 다른 테넌트의 접근이 원천 차단됩니다.
외부 웹 공개 마스터 스위치 (Allow Public Sharing)
1:1 사이드카 테이블(`workspace_public_settings`) 기반의 물리적 킬스위치
활성화 (ON)
스위치가 ON이면 승인된 공개 위키(/p/[slug])가 외부에 안전하게 열립니다. OFF로 전환 시 모든 공개 엔드포인트 조회가 DB RLS 엔진 레벨에서 즉각 404로 일괄 차단(Instant Kill Switch)됩니다.
