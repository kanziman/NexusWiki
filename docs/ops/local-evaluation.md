# 로컬 평가 실행과 누적 비교

공개 회귀 분석 화면의 실행 기능은 로컬 개발 환경에서만 활성화한다. 운영 빌드의
`/api/local-evaluation`은 항상 403을 반환한다. 개발 서버도 반드시 루프백에 바인딩한다.

## 시작

저장소 루트에서 실행기를 시작한다.

```bash
.venv/bin/python scripts/local_evaluation_server.py
```

별도 터미널의 `apps/dashboard`에서 개발 서버를 시작한다.

```bash
LOCAL_EVALUATION_ENABLED=1 pnpm dev --hostname 127.0.0.1 --port 54410
```

`http://127.0.0.1:54410/showcase/regression`의 로컬 평가 실행에서 이름을 입력하고 실행한다.
초기 기준은 보존된 합성 HTTP 1이다. 완료 결과는 로컬 누적 실행에 추가되고 지정된 기준과
자동 비교된다. 기준 지정도 새로고침과 실행기 재시작 이후 유지된다.

## 실행 종류

- 저장 답변 재채점: 현재 기대 표현과 채점 코드로 보존된 답변을 다시 검사한다. 모델을 호출하지
  않는다. 표시되는 모델 비용·토큰·지연은 원본 기록이며 재채점의 새 비용이나 속도가 아니다.
- 새 답변 생성: 로컬 재생 API·워커를 먼저 준비하고 실행기에 아래 설정을 추가한다.

```bash
.venv/bin/python scripts/local_evaluation_server.py \
  --state .worktrees/reliability-evidence-20261108/state.json \
  --api-url http://127.0.0.1:8031
```

API·워커 준비 방법은 `scripts/ask_replay_serve.sh`와 `docs/ops/ask-sample-replay.md`를 따른다.
API 건강 확인이 성공해야 화면에서 유료 실행을 선택할 수 있다. 유료 실행 준비 상태가
공급자 크레딧이나 워크스페이스 예산의 충분함까지 보장하지는 않는다.

실행별 목표 상한은 $0.20~$2.00, 문항 수는 1~30이다. 다음 질문 전에 최소 $0.20 또는
관측한 최대 문항 비용으로 남은 금액을 확인한다. 공급자 비용 보고 지연·추정 오차가 있어
절대 지출 보장은 아니다. 비용 미기록 문항은 즉시 중단하며 기존 워크스페이스 예산도 적용된다.
운영 예산·모델 설정을 자동 변경하지 않는다.

## 보존과 실패 처리

`.worktrees/evaluation-dashboard/`에 실행·부분 원본·진행 상태·기준 지정을 저장한다.
채점 코드를 수정했다면 실행기를 재시작한 뒤 새 평가를 요청한다. 실행 중인 Python 프로세스는
기동할 때 로드한 채점 함수를 사용한다.
토큰 파일과 원본은 외부로 공개하거나 커밋하지 않는다. 프록시는 토큰을 서버에서만 읽는다.
유료 실행은 문항마다 답변을 체크포인트한다. 중단·부분 실행·비용 미기록은 정상 완료 후보로
추가하지 않는다. 실행기를 재시작하면 진행 중이던 작업은 중단됨으로 표시하고 부분 답변을 남긴다.

동시 실행은 한 건으로 제한한다. 실행기 종료는 해당 터미널에서 Ctrl-C로 한다.
이 기능은 정기 평가·운영 로그 자동 수집이나 CI/CD 배포 차단을 추가하지 않는다.
