<objective>
Prove the phase's foundational architecture end-to-end on one real path: an unauthenticated
visitor is gated by `middleware.ts` (the sole cookie-writer, D-02), signs in with email +

`server.ts`) and the middleware gate this plan establishes.

Purpose: prove the `@supabase/ssr` session/cookie boundary and the "direct PostgREST read with
requester JWT" pattern (API-04's RSC carve-out) before any other surface builds on either.
Output: a working login -> gated workspace shell, plus the design-token `@theme` integration
every later component consumes.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser -> middleware.ts | Unauthenticated request first touches the tenant gate; must not be bypassable (CVE-2025-29927) |
| Browser -> Supabase Auth | Email+password credentials cross this boundary in the clear over TLS to Supabase's GoTrue endpoint |
| Server Component -> PostgREST | RSC reads use the requester's own session JWT; RLS is the only isolation enforcement, not application code |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-01 | Spoofing | middleware.ts | high | mitigate | `x-middleware-subrequest` bypass is closed by Next.js >=15.2.3 (already the pinned dashboard version, 15.5.22); middleware.ts is the ONLY cookie writer (D-02) so no parallel auth path can diverge from it |
| T-06-02 | Information Disclosure | app/w/[workspaceId]/layout.tsx | medium | mitigate | RLS 0-row result (not-a-member OR doesn't-exist) redirects to `/` uniformly — never a distinct "not found" vs "forbidden" render, per D-12 no-enumeration convention inherited from 02-CONTEXT.md |
| T-06-03 | Tampering | Session storage | high | mitigate | Session lives only in the httpOnly cookie `@supabase/ssr` writes; nothing in `apps/dashboard` reads/writes `localStorage`/`sessionStorage` for auth state (prohibition, verified by grep in Task 1) |
