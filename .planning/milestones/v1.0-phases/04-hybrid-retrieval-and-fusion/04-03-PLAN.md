## Flagged assumptions requiring manual confirmation

- RTV-01: concurrency is defined as creating all four adapters before awaiting results, via `asyncio.gather(..., return_exceptions=True)` or an equivalent observable barrier.
- RTV-05: raw hit IDs are safe only in authenticated internal retrieval metadata; provider errors/content never are.
- RTV-07/RTV-09: graph-on is a policy experiment and a graph-disabled channel must be `disabled`; a failed query embedding marks exactly both dense channels unavailable.
