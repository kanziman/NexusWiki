<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Ingested source text (file/URL/text, all untrusted) -> `source_chunks.content` -> future Ask context blocks | The one point where a source-embedded prompt-injection payload shaped like a citation anchor must be neutralized before it can ever reach an LLM context |
| Client-supplied `template_id` -> `prompt_templates` read | Untrusted string; must not become an oracle for "does template X exist in workspace Y" |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
