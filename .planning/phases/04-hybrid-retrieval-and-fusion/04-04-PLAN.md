<objective>Make retrieval quality and tuning decisions reproducible rather than anecdotal, then explicitly record the strict/relaxed and graph-off/on decisions.</objective>

## Flagged assumptions requiring manual confirmation

- RTV-04: select a production order mode only after same corpus/golden/policy/model/hardware comparison; no benchmark result licenses a silent policy mutation.
- RTV-06: 30–50 is accepted as inclusive and each label must be evidence-derived, not synthetic query-text mirroring.
- RTV-07: graph value is measured as graph-on minus graph-off per query and aggregate; the safe default stays off absent an approved recorded benefit.
